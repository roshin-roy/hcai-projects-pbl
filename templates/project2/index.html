Feature effect plots

Pick one of the four numeric features to see its effect on the predicted probability of each species, using the model currently selected above.
PDP shows the average prediction when a feature is varied. ALE uses local prediction changes within intervals of the selected feature.

ALE here uses binned finite differences for both model types. Logistic regression is differentiable, so its partial derivatives could be computed analytically; a decision tree is piecewise constant and has no derivative at its split points, so discretization is the only option there.
