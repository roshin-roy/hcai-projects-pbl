Learning-to-Defer for AG News

In this project, we use the AG News dataset to examine how a text classifier can work with an imperfect expert. For each article, the system must decide whether to keep the classifier's prediction or ask the expert.

Learning-to-Defer

We compare two ways of deciding when to consult the expert. The first uses a threshold on the classifier's confidence. The second learns from examples for which both classifier and expert predictions are available.

Strategy 1: Confidence threshold

If the classifier's confidence falls below the threshold, the article is sent to the expert. The threshold is selected using the tuning data and is not changed on the test set.

Strategy 2: Learned policy

The learned policy is a logistic regression model. Its training target is one when the classifier is wrong and the expert is correct. The inputs are the four class probabilities, maximum confidence, prediction entropy, and the classifier's predicted class.

How to interpret the deferral outcomes

Outcome Classifier Expert Meaning
Helpful Wrong Correct The expert corrects the classifier's error.
Harmful Correct Wrong Deferring changes a correct answer into a wrong one.
Both correct Correct Correct The answer stays correct, but deferring was unnecessary.
Both wrong Wrong Wrong The answer stays wrong; the expert did not introduce a new error.
Missed Wrong Correct The expert could have helped, but the system did not defer.
Correctly kept Correct Not used The system kept a correct classifier prediction.

The system's improvement over the classifier can be verified using:
(Helpful deferrals − Harmful deferrals) ÷ Number of test examples

Active Learning for Expert-Competence Discovery

We now assume that no expert labels are available initially. The system has a limited expert-query budget and must use those queries to estimate where the expert is reliable.

We compare uncertainty sampling with random sampling. Uncertainty sampling selects articles for which the classifier has the lowest maximum probability.
